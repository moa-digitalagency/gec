# Guide Utilisateur - GEC

## Introduction

Bienvenue dans le GEC (Gestion Électronique du Courrier). Cette application vous permet de gérer l'ensemble du cycle de vie des courriers administratifs : enregistrement, numérisation, transmission, traitement et archivage.

---

## 1. Premiers Pas

### Connexion
1. Accédez à l'URL fournie par votre administrateur.
2. Entrez votre identifiant et mot de passe.
3. **Note :** Après 8 tentatives échouées, votre accès sera bloqué pour 15 minutes.

### Tableau de Bord (Dashboard)
Dès la connexion, vous accédez à une vue d'ensemble :
*   **Statistiques :** Vos courriers du jour, de la semaine.
*   **Derniers courriers :** Liste rapide des éléments récents auxquels vous avez accès.
*   **Menu latéral :** Accès rapide à toutes les fonctionnalités (Enregistrer, Rechercher, etc.).

---

## 2. Traitement du Courrier

### Enregistrer un Courrier
1. Cliquez sur **"Nouveau Courrier"**.
2. Choisissez le type : **Entrant** (reçu de l'extérieur) ou **Sortant** (émis par vos services).
3. Remplissez les champs obligatoires (marqués d'un astérisque) :
    *   **Objet :** Soyez précis.
    *   **Expéditeur/Destinataire :** L'entité concernée.
    *   **Date :** Date de rédaction du document physique.
4. **Pièce Jointe :** Le scan du document est obligatoire (PDF ou Image). Le système vérifiera la taille et le format.
5. Validez. Un **Numéro d'Accusé de Réception** unique est généré (ex: `GEC-2025-00123`).

### Consulter et Rechercher
*   **Recherche Rapide :** Utilisez la barre en haut pour chercher par numéro, objet ou contact.
*   **Filtres Avancés :** Via le menu "Recherche", filtrez par date, statut, type ou département.
*   **Détails :** Cliquez sur un courrier pour voir sa fiche complète, l'aperçu du PDF, et l'historique.

### Modifier le Statut
Le cycle de vie d'un courrier évolue : `RECU` → `EN COURS` → `TRAITE` → `ARCHIVE`.
Pour changer le statut :
1. Ouvrez le courrier.
2. Cliquez sur le bouton de statut actuel.
3. Sélectionnez le nouvel état.

---

## 3. Collaboration et Workflow

### Transmission (Transfert)
Pour envoyer un courrier à un collègue ou un autre département :
1. Sur la fiche courrier, cliquez sur **"Transmettre"**.
2. Sélectionnez le destinataire (Utilisateur).
3. Ajoutez un message explicatif (optionnel) ou une pièce jointe spécifique (ex: note de transmission).
4. **Important :** Le destinataire recevra une notification et obtiendra automatiquement le droit de voir ce courrier, même s'il est hors de son département.

### Commentaires et Annotations
En bas de la fiche courrier, vous pouvez ajouter :
*   **Commentaires :** Remarque générale.
*   **Instructions :** Directive de traitement (ex: "A traiter pour demain").
*   **Annotations :** Note technique.
Ces ajouts sont horodatés et signés de votre nom.

### Notifications
La cloche en haut à droite vous alerte :
*   Lorsqu'un courrier vous est transmis.
*   Lorsqu'un commentaire est ajouté sur un de vos courriers.
*   Vous pouvez marquer les notifications comme "Lues".

---

## 4. Fonctionnalités Avancées

### Export PDF
Vous pouvez générer une fiche PDF officielle pour chaque courrier (ou une liste de résultats de recherche) en cliquant sur le bouton **"Exporter PDF"**. Ce document inclut le logo de l'organisation et toutes les métadonnées.

### Gestion du Profil
Cliquez sur votre nom en haut à droite pour :
*   Changer votre photo de profil.
*   Modifier votre mot de passe (Recommandé régulièrement).
*   Changer la langue de l'interface (Français/Anglais/etc.).

### Corbeille
Si vous avez les droits de suppression, les courriers effacés vont dans la **Corbeille**. Ils peuvent être restaurés tant qu'un administrateur ne les a pas supprimés définitivement.

---

## 5. Astuces et Raccourcis

*   **Dates :** Le format standard est `JJ/MM/AAAA`.
*   **Sécurité :** N'oubliez pas de vous déconnecter (Logout) si vous utilisez un ordinateur partagé.
*   **Support :** En cas de problème technique, notez le message d'erreur et contactez votre administrateur.
